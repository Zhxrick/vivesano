# ViveSano – Prototipo navegable

Prototipo de una página web de recomendaciones saludables (alimentación, actividad física, descanso y bienestar).
Actividad de Construcción Aplicada (ACA) – Ingeniería Web – CUN, 2026. Autora: Zharick Carolina Donado Caliz.

- Prototipo: abrir `index.html`
- Wireframe (baja fidelidad): agregar `?modo=wireframe` a la dirección
- Usuario administrador de prueba: `admin@vivesano.co` con cualquier clave de 8 o más caracteres

Hecho con HTML5, CSS3 y JavaScript. Los datos son simulados y se guardan solo en el navegador.
